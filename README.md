# Encounter : NightDance

**HD-2D Style SRPG Project**
기존 프로젝트의 로직을 개선하고, CS 지식을 바탕으로 더욱 견고한 구조로 리팩토링하여 다시 개발 중인 프로토타입입니다.
3D 라이팅과 셰이더를 활용한 배경 위에 2D 캐릭터가 공존하는 2.5D 그래픽을 지향합니다.
